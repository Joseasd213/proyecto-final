Documentos necesarios

DNI

Necesitarás:

  • ✓ DNI anterior
  • ✓ Foto reciente 32x26 mm
  • ✓ Pago de la tasa
  • ✓ Empadronamiento si cambia el domicilio
  • ✓ Denuncia policial si fue robado o perdido

NIE / TIE

Necesitarás:

  • ✓ Pasaporte original y copia
  • ✓ TIE anterior
  • ✓ Formulario EX-17
  • ✓ Fotografía reciente
  • ✓ Justificante de pago
  • ✓ Empadronamiento actualizado
